# 从零训练大语言模型

> **一句话定位：** 以一个可运行、可复现的迷你 LLM 项目（[zllm](../../README.md)）为主线，从数学基础一路讲到 Agent RL，带你亲手训练、微调并部署一个大语言模型——读懂每一行实现代码，跑通全流程。

## 读者画像

- 有 Python 编程基础、了解基本机器学习概念的开发者；
- 希望系统建立「数学 → 深度学习 → Transformer → 预训练 → 对齐 → 推理部署」完整知识闭环的工程师或研究生；
- 不满足于「调包」，想真正读懂实现、亲手跑通每一阶段的动手派。
