# 设计：用引用式 SVG 替换 ch01 的 ASCII 图

- **日期**：2026-07-03
- **范围**：仅 `docs/book/part-1-math/ch01-linear-algebra-vectors.md` 中的 2 张 ASCII 图
- **状态**：待 review

## 1. 背景与问题

`ch01-linear-algebra-vectors.md` 全章共有 3 处「图」：

1. **标量→向量→矩阵→张量** 概念图（第 61–70 行）：已是 mermaid `graph LR`，**保留不动**。
2. **点积 = 投影长度**（第 208–221 行）：ASCII art。
3. **矩阵乘法 = 线性变换（旋转+缩放）**（第 245–256 行）：ASCII art。

全书的图示约定是 **mermaid**（共 20 处，横跨所有章节）。但 mermaid 是图/流程图工具，**画不了**几何向量图（旋转箭头、夹角弧、投影垂线、before/after 向量对）。结果是 ch01 出现了**全仓唯一的 2 处 ASCII art** —— 它们不是风格选择，而是「mermaid 力所不及时的临时兜底」。

ASCII art 的问题：在不同字体/渲染器下错位、无法表达角度与长度、与全书 mermaid 风格不一致、削弱本章「在脑子里画出几何图像」的核心目标。

## 2. 目标 / 非目标

**目标**
- 用清晰、可缩放、版本友好的几何图替换 2 张 ASCII 图。
- 与「全书目前是纯文本、无构建管线、无静态站点配置」的现实兼容。
- 在作者当前的主要浏览方式（GitHub 渲染 `.md`）下原生显示。

**非目标（明确排除）**
- 不做全书范围的图示策略升级（其它章节几何图留待将来各自处理）。
- 不引入构建管线 / 生成脚本（matplotlib、TikZ 等）。
- 不改 mermaid 那张概念图。
- 不触碰 ch01 正文文字（仅替换两个代码块）。

## 3. 关键约束（已核实）

| 约束 | 结论 |
|------|------|
| 作者主要在哪看 | GitHub/GitLab 渲染 `.md` |
| GitHub 是否支持 `.svg` | 是 —— `.svg` 在官方「支持的图片类型」列表中，`![alt](figs/x.svg)` 原生渲染 |
| GitHub 是否支持内联 `<svg>` HTML | 不可靠 —— 安全过滤会剥离；故**采用「引用独立 .svg 文件」而非内联** |
| GitHub 是否保留 SVG 动画 | 否 —— 安全过滤会剥离 SMIL/CSS 动画与脚本，`.svg` 以静态图片呈现 |
| 直接浏览器打开 `.svg` / 未来静态站点（MkDocs/Quartz/Docusaurus） | 动画可播 |
| 现有图示约定 | mermaid（流程图类）；几何类尚无约定 → 本次为几何图建立「引用式 SVG」先例 |

## 4. 方案选型（已与用户确认）

在「引用式 SVG / mermaid 硬画 / 生成脚本」三选一中选 **引用式 SVG**：

- ✅ GitHub 原生渲染；✅ 几何精度满足这两张图的需求；✅ 纯文本 XML、diff 友好、版本友好；✅ 零构建；⚠️ 引入一个 `figs/` 目录（几何图的不可避免成本）。

**动画策略（用户选 B）**：书内嵌**静态** SVG（处处可见）；为每张图**额外**存一份 `_anim.svg` 动画版，供将来 web 渲染或直接浏览器打开使用。两份并存，书内只引用静态那份。

## 5. 视觉风格（已确认：风格 B「彩色简洁」）

| 元素 | 规格 |
|------|------|
| 画布 | `viewBox="0 0 380 250"`，白底 |
| 字体 | `font-family="Cambria, Georgia, serif"`，变量斜体 |
| 向量 x | 描边 `#2563eb`（蓝），`stroke-width="2.6"`，带箭头 |
| 向量 y / A·x | 描边 `#ea580c`（橙），`stroke-width="2.6"`，带箭头 |
| 投影垂线 / 旋转弧 | `#9ca3af` / `#6b7280`，虚线 `stroke-dasharray="6 4"`，`stroke-width≈1.6/1.4` |
| 坐标轴 | 细参考线 `#cbd5e1`，`stroke-width="1"` |
| 原点 O | 实心小圆点 + 标签 |
| 说明文字 | `#6b7280`，小号，斜体（如 `proj = ‖y‖·cosθ`） |
| 箭头 | SVG `<marker>`，颜色随各向量 |

风格 B = 有色彩区分、有 θ/α 弧与虚线投影、但**无坐标网格**，保持干净、不喧宾夺主。

## 6. 交付物

新建目录 `docs/book/part-1-math/figs/`，产出 4 个文件：

| 文件 | 用途 |
|------|------|
| `figs/ch01-dot-product-projection.svg` | 图1 静态（入书引用） |
| `figs/ch01-dot-product-projection_anim.svg` | 图1 动画版（y 扫动 θ，投影/弧跟随；不入书引用） |
| `figs/ch01-matrix-transform.svg` | 图2 静态（入书引用） |
| `figs/ch01-matrix-transform_anim.svg` | 图2 动画版（向量在 x ↔ A·x 间形变；不入书引用） |

**命名约定（为将来其它章节留先例）**：`<chapter>-<topic>.svg` 静态；`<chapter>-<topic>_anim.svg` 动画。

### 6.1 图1 几何（点积 = 投影）
- 原点 O=(40,205)，x 轴水平；向量 **x** 沿 x 轴向右（蓝）；向量 **y** 与 x 成 θ≈35°（橙，长 175）；从 y 尖端垂直到 x 轴的虚线 = 投影（`proj = ‖y‖·cosθ`）；原点处 θ 弧；右角小直角符号。
- 动画版：y 在 θ∈[18°,72°] 间来回扫动（6s/轮），投影垂线与 θ 弧的端点用 SMIL `<animate values=...>` 同步跟随，演示「θ→0 投影最大、θ→90° 投影归零」。

### 6.2 图2 几何（矩阵 = 旋转 + 缩放）
- 原点 O=(60,210)；输入向量 **x**（蓝，20°，长 110）；输出 **A·x**（橙，60°，长 176 = 旋转 +40°、缩放 ×1.6）；二者间画带箭头的 α 旋转弧；一条淡虚线弧暗示长度拉伸；标注 `旋转 α · 缩放 ×1.6`。
- 动画版：橙色向量在 x 尖端 ↔ A·x 尖端间连续形变（4s/轮），输入 x 以半透明留作参照，直观演示「矩阵把 x 旋转 α 又拉伸」。

## 9. 风险 / 备注
