# 矩阵乘法 SVG 动画设计

## 目标

为 ch01-linear-algebra-vectors.md 的「矩阵与矩阵乘法」部分创建一个交互式 SVG 动画，展示矩阵乘法的计算过程。

## 需求

### 用户需求
- 参考文件：`figs/ch01-dot-product-calc_anim.svg`
- 目标位置：`ch01-linear-algebra-vectors.md` 的「矩阵与矩阵乘法」部分
- 动画内容：整体矩阵结构 + 逐格计算过程
- 矩阵维度：2×3 和 3×2 矩阵相乘，得到 2×2 结果

### 功能需求
1. 展示矩阵 A (2×3) 和矩阵 B (3×2) 的整体布局
2. 逐格动画展示 4 个元素的计算过程
3. 高亮当前计算的行（A）和列（B）
4. 显示点积计算过程和结果

## 设计

### 布局结构

```
┌─────────────────┬─────────────────┬─────────────────┐
│   矩阵 A        │   矩阵 B        │   结果 C        │
│   (2×3)         │   (3×2)         │   (2×2)         │
│                 │                 │                 │
│   [1 2 3]       │   [7  8]        │   计算过程      │
│   [4 5 6]       │   [9  10]       │   逐格展示      │
│                 │   [11 12]       │                 │
└─────────────────┴─────────────────┴─────────────────┘
```

### 示例数据

```
A = [1 2 3]    B = [7  8]     C = A×B = [58  64]
    [4 5 6]        [9  10]              [139 154]
                   [11 12]
```

计算公式：
- C₁₁ = 1×7 + 2×9 + 3×11 = 7 + 18 + 33 = 58
- C₁₂ = 1×8 + 2×10 + 3×12 = 8 + 20 + 36 = 64
- C₂₁ = 4×7 + 5×9 + 6×11 = 28 + 45 + 66 = 139
- C₂₂ = 4×8 + 5×10 + 6×12 = 32 + 50 + 72 = 154

### 动画时间轴（10秒循环）

| 时间段 | 内容 | 动画 |
|--------|------|------|
| 0-1s | 显示矩阵 A、B 结构 | 淡入 |
| 1-2.5s | 计算 C₁₁ | 高亮 A 第1行、B 第1列，显示计算过程 |
| 2.5-4s | 计算 C₁₂ | 高亮 A 第1行、B 第2列，显示计算过程 |
| 4-5.5s | 计算 C₂₁ | 高亮 A 第2行、B 第1列，显示计算过程 |
| 5.5-7s | 计算 C₂₂ | 高亮 A 第2行、B 第2列，显示计算过程 |
| 7-9s | 显示完整结果 C | 结果矩阵高亮 |
| 9-10s | 淡出重置 | 准备下一次循环 |

### 视觉设计

#### 颜色方案（与参考一致）
- **蓝色** (`#2563eb`): 矩阵 A 的行元素
- **橙色** (`#ea580c`): 矩阵 B 的列元素
- **绿色** (`#059669`): 中间计算结果
- **紫色** (`#7c3aed`): 最终结果元素
- **灰色** (`#9ca3af`): 网格和辅助线

#### 元素样式
- 矩阵括号：使用 `<path>` 绘制，确保跨字体一致性
- 高亮元素：圆形边框，填充透明度 0.2
- 网格背景：虚线网格，透明度 0.3
- 暗色模式：通过 CSS 媒体查询支持

### 技术实现

#### SVG 结构
```xml
<svg viewBox="0 0 700 320">
  <!-- 样式定义 -->
  <style>...</style>
  
  <!-- 网格背景 -->
  <rect fill="url(#grid)"/>
  
  <!-- 矩阵 A (2×3) -->
  <g id="matrix-A">...</g>
  
  <!-- 矩阵 B (3×2) -->
  <g id="matrix-B">...</g>
  
  <!-- 结果矩阵 C (2×2) -->
  <g id="matrix-C">...</g>
  
  <!-- 计算过程显示 -->
  <g id="calculation">...</g>
</svg>
```

#### 动画实现
- 使用 SVG `<animate>` 元素
- `keyTimes` 属性控制时间点
- `opacity` 控制显示/隐藏
- `fill-opacity` 控制高亮强度

#### 响应式设计
- `viewBox` 确保缩放适配
- `width="100%"` 自适应容器宽度
- 系统字体栈确保跨平台一致性

### 插入位置
在以下位置之后插入：
```markdown
### 矩阵与矩阵乘法

**矩阵**是排成 $m$ 行 $n$ 列的数表...

设 $A \in \mathbb{R}^{m \times p}$ 、 $B \in \mathbb{R}^{p \times n}$ ...

$$
(AB)_{ij}  =  \sum_{k=1}^{p} A_{ik}  B_{kj}
$$

请仔细看这个公式的下标...

> **矩阵乘法 = 「取 $A$ 的一行、取 $B$ 的一列、做点积」填进结果矩阵的对应位置。**
```

插入内容：
```markdown
下面这张动画展示了矩阵乘法的**具体计算过程**（以 2×3 和 3×2 矩阵为例）：

![矩阵乘法计算过程](figs/ch01-matrix-multiplication_anim.svg)

可以看到，矩阵乘法就是「行×列做点积」——每一格结果都是 A 的一行与 B 的一列的点积。
```
